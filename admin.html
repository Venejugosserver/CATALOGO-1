Promociones del mes

Cada promoción aparece como banner en el catálogo mientras esté activa y dentro de sus fechas. Si tiene un % de descuento, se aplica a sus productos (cuando un producto también tiene descuento propio, se usa el mayor).

Cargar descuentos del mes desde Excel

Sube un archivo con una columna de código, ID o producto, y una columna de descuento (15, 15% o 0,15). Puedes asignar los descuentos directo a los productos o crear con ellos una promoción.

Actualizar productos desde Excel

Acepta .xlsx, .xls y .csv. Detecta solo las columnas (código, producto/nombre, descripción, marca, categoría, precio, descuento, cantidad/stock, módulo, imagen, ID), aunque el encabezado no esté en la primera fila. Los precios con coma (2,22) se leen correctamente. Cada fila se empareja con el producto existente por ID, luego por código y luego por nombre + marca, así las fotos y promociones no se pierden ni se cruzan.

Fotos en lote

Nombra cada archivo con el código, el ID o el nombre exacto del producto (por ejemplo 7UP-15.jpg, 587.png o ACEITE SOYA PORTUMESA 12 X 850 ML.webp). Solo se aceptan coincidencias exactas para no asignar una foto al producto equivocado; las que no coincidan puedes asignarlas a mano. Las fotos se optimizan automáticamente (máx. 900 px, formato WebP).

Conexión con GitHub
